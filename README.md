A renamed planet: "Mars is now 'Refund Planet' — we spent billions looking
for water there and all we found was a rock that charges rent in dust
storms." The program writes it to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
